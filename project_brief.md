# My agent: Stride - Endurance & Running Coach
One-liner: A conversational agent that helps runners prepare for races and dial in their pacing with a catalog of structured running workouts, training plans, and gear.

Tool coverage:
- Memory: Target race distance and date, recent race PRs, base weekly mileage, easy aerobic pace, past injury history, and running shoe mileage.
- Tools: Filter workouts by session type (tempo, intervals, long run, recovery), log completed training runs, and look up shoe/gear specs.
- Catalog/UI: Catalog of structured workouts with pace targets and weekly training schedules rendered as A2UI cards and summary tables.
- Image gen: Finish-line celebrations, custom milestone badges, and scenic race-day visualizations.
- Sandbox: VDOT running pace calculations (Jack Daniels formula), race split projections (even vs. negative splits), heart rate training zones, and weekly mileage ramp progressions.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for VDOT pacing formulas and race splits, Google Maps API for route terrain/elevation, Cloud Trace for tool call latency monitoring.
